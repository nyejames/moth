## Delivery contract

A **closure** is a contextual expression such as `|text| => EditMessage::Rename(id, text)`. A library declares a **callback parameter** or **callback field** to receive it. Here `text` is an invocation argument and `id` is a lexical capture. A literal with no lexical captures uses the same form. Deliver scoped readers and edits, message construction and Moth-owned component handlers. Event transport, browser registration and redraw scheduling belong to the consumer.

Read the [Closures reference](../../docs/closures/closures.mtf), [parameter brackets](../../moth-surface-syntax-design.md#parameter-brackets), [Channels contract](../../docs/async/channels.mtf), [memory authorities](../../developer-docs/memory-management/overview.mtf), [compiler architecture](../../compiler-design-overview.md) and [build architecture](../../build-system-design.md). Follow [AGENTS.md](../../../AGENTS.md) for routed testing, validation and the Slice review. Source paths below starting with `ast/`, `hir/` or another frontend module are relative to `src/compiler_frontend/`.

- **Signature and expression.** Declare `format |value I32| -> String`. The literal `|n| => expr` receives its types from that slot. Named invocation arguments use declaration names. Literal binders obey no-shadowing. Accept zero or one ordinary success value, including an optional result. Omit the arrow for zero results. Type the single expression in return context. Reject unanchored literals, statement bodies, extra success slots and explicit callback error slots. A callback signature cannot itself declare further callback parameters. No first-class function type, callable traits, bare callback returns or const closures.
- **Capture and access.** Resolve free runtime places once. Shared access is the default. An exclusive use requires the ordinary `~` marker. Compare captures with other captures and arguments using resolved places and access rules. A callback can be invoked zero or more times and cannot consume a capture on the assumption it will run once. `saved = copy items` before formation takes one snapshot. `copy items` inside the body runs on every invocation.
- **Execution and failure.** Every invocation must be provably non-suspending through helpers, imports and implicit child joins. The containing function can wait between calls, subject to its live loans. An opaque invocation can fail implicitly and may trap or use fast arithmetic. Apply ordinary recovery, private propagation and exported error-boundary rules. A later invocation reports failure to its invoker. A registration that also invokes synchronously can observe that invocation's failure.
- **Retention.** A plain callback is call-bounded. `into this`, `into owner` and `into return` permit retention in the writable receiver, a named writable parameter or the single success owner, respectively. Check the destination on every storing or forwarding path. A retained environment may share readable values that outlive it. Lend mutable model state per invocation. A field can be invoked, replaced or lent to a plain parameter while its owner is live. V1 rejects retained exclusive captures and independently retaining an extracted field.
- **Copy and absence.** A stored callback is non-copyable even if it captures nothing. Ordinary binding or a legal return can preserve the owner. Represent an absent handler with an ordinary optional holder containing a required callback field. `on_edit || -> String?` declares a required callback whose result may be absent.
- **Borrowed results.** For an opaque invocation account for all possible sources in the inputs and captured environment, including nested retained references. A result can be consumed while those sources are live. An escaping result needs an outlives proof for each possible source or an independent copy while valid. Existing region placement can supply evidence when available. Last-use optimisation and GC cannot make an unproved escape legal.

## Phase 1. Establish trustworthy effects across calls

- [ ] Reuse `PublicCallSummary`, `hir/failure_facts.rs` and `module_compilation/generated/{convergence,constraint_convergence}.rs` for ordinary calls and generated bodies. Separate recoverable failure, traps, fast semantics and suspension. A signature-only initial value supplies no proof. Among these effects an opaque callback guarantees only non-suspension. A helper need not spell `$no_suspend` when its settled evidence proves it. A local catch cannot discharge a possible trap or prove [safe arithmetic](../../docs/directives/constraints.mtf).
- [ ] Consume the Channels suspension proof if delivered. Otherwise establish the smallest shared proof at the ordinary call owner with an actual named-code consumer. Unannotated proven helpers pass. Unknown foreign effects, a reachable wait or a possibly suspending implicit join prevent proof. Contrast a closed recursive component with one reaching an unknown foreign call. Verify local and imported paths. Do not require a scheduler or introduce closure-specific suspension analysis.
- [ ] Publish verified effects on the existing concrete call summary. Verify that changing a provider helper's effect reaches a fresh consumer, including through a re-export and generic specialization. Test warm invalidation only where semantic reuse exists.
- **Phase 1 audit.** Apply the [eight-kind gate](#audit-closeout-for-every-phase) to effect production, convergence, publication and consumption. Exercise effects on ordinary named calls here. The invocation-versus-registration control runs in phase 3. Land reusable proof changes only with a working consumer.

## Phase 3. Integrate the closure surface

Deliver one tested public cutover. Stage the following units against the same revision. Each unit must pass its producer/consumer controls before integration. Bring the scoped HTML-Wasm witness up first so an unsupported call ABI cannot remain hidden until cutover.

1. **Parse once and type at the receiver.** Extend `declaration_syntax/signature_members.rs` and its member contexts for parameters, fields and trait requirements. Parse the inner signature at its own delimiter depth. Exercise a callback before another outer parameter, empty inner brackets, an optional result and a trait receiver. Reuse `ast/expressions/call_arguments.rs::parse_call_arguments_with_receiving_context` for routing and `struct_instance.rs` in the same directory for constructor expectations. Resolve `row.on_edit` in `ast/field_access/parse_chain.rs`: a following argument list invokes the resolved field, while a plain receiving slot can borrow it. Preserve field/method collision checks. Use the ordinary function-body and return-expression typing machinery for the closure body.
2. **Project the whole callable contract.** Represent ordinary value slots and callback signatures without a dummy value type for zero results. Today `PublicFieldTypeSlot` is shared with choice payloads and the public trait parameter contract projects `This` separately. Extend the existing parameter identity traversal, struct dependency visit in `public_interface/interface_closure.rs`, trait projection and `ast/module_ast/environment/builder/import_projection/nominal.rs`. Visit every input and result type. A function type ID alone omits parameter access. Add the callback signature and its retention destination to the live receiving slot in `public_interface/model.rs`. Restrict callback storage declarations to named struct fields. Verify a nominal type reachable *only* through an exported callback field or parameter, access mismatch in conformance and a generated instance. Change only a provider's retention destination and prove the previously legal forwarding call fails in a freshly compiled consumer. Recreate the hidden-type and sidecar scenarios recorded in the retirement evidence with callback-only input and result types. Consumer-local IDs must be reconstructed from stable identities.
3. **Form and invoke through HIR.** Give each body a private executable identity and record resolved captures once. Use a stable origin when it must cross an artefact or generic sidecar boundary. Keep capture-free environments cheap. `external_packages/ids.rs::CallTarget` describes direct targets. Model invocation through a callback operand explicitly. Reuse authored operand ordering in `hir/hir_expression/calls.rs`, the existing fallible `Invoke` continuation in `hir/terminators.rs` and its operand traversal. Include the environment and actual invocation arguments in validation and borrow uses. In `hir/reachability.rs`, a reachable formation may require the body and its private dependencies to be linked. Only invocation executes it and contributes its body effects. Dead formation must not create target demand. Avoid per-literal specialization of every receiving function.
4. **Check stores, copies and use sites.** Validate plain versus retained forwarding against the declared destination at the provider and capture legality at the caller. A factory may forward into the very owner it returns. A setter may call, skip or replace its handler. Preserve committed effects on failure. For `copy`, first resolve a place through `ast/expressions/parse_expression_places.rs::parse_copy_place_expression`. The current place check cannot detect a valid operand containing a non-copyable field. Reuse or complete the ordinary semantic graph-copy eligibility check after type resolution. Locate the offending member through resolved nominal/instantiated fields with cycle protection. Keep one source of that decision for all backends. Apply the [diagnostic cases](#diagnostic-acceptance) before lowering.
5. **Lower and check target support.** Execute scoped and retained cases on HTML-JS. HTML-Wasm currently has direct function/import targets in `src/backends/wasm/lir/instructions.rs::WasmCalleeRef`. `validate_wasm_fallible_control_flow` rejects selected `Invoke`, `ReturnError` and signatures with an error channel. Preserve the exact Wire read/forward workload through a real scoped call path. A bounded proof may resolve a known target and discharge failure across the entire selected forwarding path, including its signatures. Otherwise implement the required invocation and recoverable failure support. A trap, getter-specific rewrite or waived fixture cannot satisfy this gate. For features beyond the supported subset, reject reachable uses before lowering, including generated bodies. Keep the restricted host ABI and independent channel-message rules. Add host rejection cases that reach the ABI with a legal callback signature. Publish only the support verified in the user reference, compiler authorities and progress matrices.

### Diagnostic acceptance

Reuse an appropriate typed diagnostic family and add distinct reasons and payload facts where the present ones cannot express the failure. Distinguish a valid place with an ineligible graph member from an invalid `copy` operand. Use `tests/cases/*/expect.toml` to assert error-code multiplicity, reason, primary path/line/column and relevant secondary locations. Use a short rendered fragment where the field path or corrective guidance is part of the contract.

| Rejected source | Required explanation and nearest accepted case |
|---|---|
| `copy row` or `copy panel` with `panel.row.on_edit` | Point to the copy use, name the callback field path and label its declaration where source is available. Explain that the owner cannot be independently copied. Copy a data field such as `panel.row.title` or use the same owner within its lifetime. Cover an imported owner and a capture-free handler. |
| `none` supplied to a required callback field | Point to `none`, label the required field declaration where source is available and suggest an optional holder for installation. Exercise absent and present `HandlerHolder?` plus a required `on_edit \|\| -> String?` returning `none` and a present String. Keep the valid optional result out of this diagnosis. |
| Retained exclusive capture, wrong retention destination or escaping result | Identify the offending use and its source or declared destination. Suggest lending the model per call for an exclusive capture. Show the shorter-lived source for an escaping result. Accept a named writable owner, writable receiver and single returned owner with valid evidence. |
| Suspending helper inside a closure | Identify the call that prevents proof and the callback's non-suspension requirement. Cover a transitive import and unknown foreign effects. A proven unannotated helper passes. |

### Execution controls

- **Read and edit.** Produce exactly `Action: Save` through an imported row-label helper. Forward `|| => owner.title` through an opaque wrapper. Even with zero invocation arguments, drawing the result immediately is legal and keeping it past the owner is rejected. Read the model again after a legal edit. Invoke `|| => increment(~count)` twice and observe two edits. Check evaluation of a side-effecting named argument beside the closure in written order. Reject a missing capture write marker, an overlapping mutable argument and a borrowed callback escaping through a helper.
- **Retained UI.** Construct a Moth-owned row with `into return`, invoke its field twice and assert both message IDs and text. Invoke a retained handler with a mutable model supplied per call. Exercise repeated rows, conditional installation, replacement and teardown. Verify that replacement removes the old field edge and that an outstanding result borrow still keeps its own sources live. A failed installation that already committed an ordinary store does not undo it.
- **Timing and effects.** Compare fallible work before formation with the same work inside a closure invoked zero, one and two times. Assert order, count and which handler receives failure. Compare a private propagating invoker with an exported invoker that must recover or expose its error boundary. Accept recovery of a named helper's custom error in the closure and reject letting the unhandled custom error escape. Check a caller-defined closure whose only route to a private helper or binding is through an imported invoker. With executable Channels, exercise a wait between completed invocations and check any loans held across it.
- **Targets and neighbours.** Pin shared outputs on both advertised targets, a reachable unsupported operation on HTML-Wasm and the same operation in dead code. Preserve ordinary constructor defaults and ordinary missing-field errors through the new callback receiving contexts.

## Audit closeout for every phase

**Run all eight kinds before advancing from each of phases 0 through 4:** Correctness, Diagnostics, Performance, Redundancy, Tests, Style, Comments and Documentation. Use the [audit guide](../audit-guide.md) and [individual checklists](../audit-kinds/README.md). Each phase above identifies the evidence to inspect.

1. The coordinator maps each phase to concrete owner areas. Dispatch one kind and one area per run. Subagents may inspect independent areas or kinds in parallel. Serialize reservations and shared index updates. Correctness records findings in the bug queue and revision coverage in the audit log. For the other seven kinds, reserve an unused report ID across open and closed reports, create its skeleton and register it before inspection.
2. Auditors inspect and record evidence. For a baseline-only phase, inspect the actual fixtures, comments, diagnostics, timings and documentation that support the baseline. A clean finding set still needs recorded coverage. Finish any excluded or partially covered phase area before closing the gate. Keep unrelated leads in the bug queue.
3. Triage each finding against the contract and its strongest counterexample. A separate implementation task fixes every valid in-scope finding in any category. A different reviewer repeats the witness, inspects affected consumers, checks that the displaced path is gone and reruns invalidated checks. Re-audit materially changed evidence. A blocked fix keeps the phase open.
4. Record evidence for rejected or superseded findings. Remove resolved bug entries in their fix commits. Archive clean or verified formal reports, update open/closed indices and the completed audits log. **Exit requires all eight kinds covered, zero valid unresolved in-scope findings and the separate [Slice review](../../../AGENTS.md).**
